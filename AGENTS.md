# Памятка для работы с проектом

## Начало работы

1. Прочитать `docs/maintenance/CURRENT_STATE.md`, `LOCAL_CHANGES.md`,
   `UPSTREAM_SYNC.md` и `VERIFICATION.md` в этой же папке.
2. Проверить актуальный код: заметки и номера прежних сборок не доказывают
   поведение установленной игры.
3. С пользователем говорить по-русски, простыми словами. Промежуточный отчёт:
   что сделано, что делается, что осталось, есть ли проблемы; 3–6 коротких предложений.
4. По умолчанию работать самостоятельно. Делегировать только по просьбе пользователя,
   для полностью независимой работы с заметным выигрышем времени или для независимой
   проверки критичного решения. Сначала объяснить практическую пользу; результат
   помощника проверить самому и пересказать простым языком.

## Границы работы

- Git-команды, коммиты и отправку выполнять только при явном запросе пользователя.
  Разрешение на восстановление и PR от 28 сентября 2026 относится к этой задаче,
  а не ко всем будущим задачам.
- Не заменять нашу ветку файлами автора целиком. Порядок обновления — в `UPSTREAM_SYNC.md`.
- Не удалять пользовательские изменения, старые сборки или резервные копии ради уборки.
- В Git входят исходники, документы и воспроизводимые инструменты. Локальные логи,
  конфигурации игры, сохранения, токены, архивы и сборки туда не входят.
- `archive/` содержит старые материалы, `artifacts/` — результаты сборки,
  `.recovery/` — материалы сравнения, `.local/` — сведения об этом компьютере.
  Их отсутствие в свежем клоне нормально.
- Корневые файлы и папку `FF14Accessibility/` сохранять совместимыми с upstream:
  массовые переименования исходников усложняют последующие обновления.
- `CLAUDE.md` и `CLAUDE.de.md` восстановлены из upstream как справочные материалы;
  локальный порядок работы описан здесь. Запуск Debug автоматически устанавливает
  плагин через проект: для обычной проверки использовать Release.

## Обязательные свойства

- Ремесленные действия из `CraftAction` записывать с типом `CraftAction`, усиления
  из `Action` — с типом `Action`. Тип сохраняется в выборе, описании, записи и проверке.
- Меню клавиатуры сначала выбирает клавишу; режим геймпада не должен перехватывать его.
- Строки журнала боя `XivChatType.Action` сохранять в истории без автоматической речи.
  Предупреждения о противнике проверяют `CombatSide.IsEnemy`.
- Числа материалов брать из выбранного рецепта только при совпадении видимого названия;
  при несовпадении использовать данные окна, не смешивать два рецепта.
- Перенос в оружейный сундук использует штатное меню игры для конкретного предмета.
  Ждать заполнения меню, проверять исходную ячейку и результат, останавливаться при
  неподтверждённом переносе. Не заменять это прямым перемещением по выдуманной ячейке.
- Русские справочники использовать только при `Loc.IsRussian`, сохраняя запасной
  вариант из игры. Новые произносимые сообщения добавлять через `AccessibilityStrings`.
- Не терять русскую локализацию и восстановленные файлы `*.V19.cs`. Суффикс V19 —
  происхождение восстановленного кода, это действующие части плагина, не старый мусор.

## Проверка и выдача

- Порядок защиты существующих функций — `docs/maintenance/REGRESSION_POLICY.md`.
  Общая команда: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Verify-Local.ps1`.
  Не обходить запрет упаковки без актуальных тестов и не скрывать предупреждения.

- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Local.ps1`
- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test-Local.ps1`
- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Package-Local.ps1`
- PowerShell с русскими строками сохранять как UTF-8 с BOM, `.bat` — с CRLF.
- Проверять состав ZIP и совпадение DLL по SHA-256. Указывать, есть ли в архиве исходники.
- Успешная сборка и тесты не доказывают работу в FFXIV. Отдельно сообщать, что
  проверено автоматически, что проверено в игре и что осталось непроверенным.
- После изменений обновить `CURRENT_STATE.md` и `VERIFICATION.md` без выдуманной
  истории проверок. Не редактировать память Codex без отдельной просьбы пользователя.
