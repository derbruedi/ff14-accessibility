## Автоповорот при AoE — версия 6.08.98

После установки этой сборки включите `/acc aoeturn on`. При распознанной
опасности персонаж и камера повернутся к проверенному прямому выходу,
а голос подскажет «Вперёд» и расстояние. Нажимайте движение вперёд сами.
Команда `/acc aoeturn off` выключает помощь, `/acc aoeturn` читает состояние.
Тот же переключатель есть в настройках по Shift+F9. По умолчанию он выключен.

Сейчас поддерживаются подтверждённые круги вокруг противника и конусы до
180 градусов. Для полос и атак с неизвестной формой или центром автоповорот
не применяется. Помощь уступает ручному повороту и движению вбок/назад,
приостанавливается в меню, чате, при Alt+Tab и автоматическом беге.
«Вперёд» произносится после повторного чтения направления персонажа и камеры,
а также повторной проверки пути. Если игра не удержала поворот, помощь
отменяется с сообщением «Поворот не подтверждён. Уклоняйся вручную».
Ctrl+F11 (личная клавиша остановки речи) и `/acc stop` сразу убирают
звуковое наведение и отменяют помощь. После изменения атак поиск
использует новые данные, а запас до края конуса считается по расстоянию.
Проверка в игре, обоих режимах движения и замер нагрузки ещё требуются.

## Где что находится

- `FF14Accessibility/` — актуальный исходный код плагина.
- `Installer/`, `docs/`, `docs-de/`, `tools/`, `templates/` — исходные инструменты
  и документация автора, сохранённые для совместимости и дальнейших обновлений.
- `AGENTS.md` — правила для помощника; начинать чтение проекта с этого файла.
- `docs/maintenance/` — состояние работы, карта наших изменений, порядок обновления,
  ограничения и проверки. Это основная документация для дальнейшей разработки.
- `scripts/Build-Local.ps1` — сборка Release без установки в игру.
- `scripts/Test-Local.ps1` — автоматические проверки.
- `scripts/Package-Local.ps1` — создание и проверка архива для ручной установки.
- `scripts/Publish-Release.ps1` — публикация проверенного архива в GitHub Releases.
- `docs/releases/` и `CHANGELOG.md` — описания выпусков для игроков.
- `artifacts/plugin/` — последняя подготовленная сборка.
- `artifacts/releases/` — ZIP для передачи; прежние архивы сохранены.
- `artifacts/logs/` — отчёты сборок и проверок.
- `archive/` — прежние материалы, которые не используются как исходники.

Каталоги `artifacts/` и `archive/` локальные: Git их не отправляет. В новой копии
проекта они создаются при сборке; архив прежних материалов остаётся на исходном компьютере.

## Сборка и упаковка

Нужны Windows, .NET SDK 10 и совместимые библиотеки установленного Dalamud API 15.
Скрипт по умолчанию ищет библиотеки в `%APPDATA%\XIVLauncher\addon\Hooks\dev`.
Для другого расположения передайте `-DalamudHome` либо задайте `DALAMUD_HOME`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test-Local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Package-Local.ps1
```

Готовый мод устанавливается через EXE либо ручным копированием содержимого
`artifacts/plugin` в зарегистрированную папку плагина. Порядок описан в
[инструкции](docs/installation.md). ZIP для игроков содержит только готовые
файлы, инструкцию и лицензии; установочные скрипты в него не включаются.

Русский автоустановщик распространяется отдельно. Его исходники, проверки
и инструкция сборки находятся в `FF14AccessibilityInstaller-1.1.2-source.zip`
на странице релиза. Начиная с v6.08.74, они также входят в исходный архив GitHub.

## Состояние

Восстановленный исходный снимок — 6.08.61, текущая версия — 6.08.86.
Главной веткой форка выбрана `feature/russian-accessibility-recovery`;
`main` сохраняет основу автора. Готовые архивы распространяются через GitHub Releases.
Основа автора — `b5ae793`, версия 6.08.34. Сравнение показало, что её изменения
уже входили в наши исходники. Восстановлены отсутствовавшие документация, тесты и инструменты.
История отдельных прежних локальных правок не сохранилась: в Git они записаны
одним честно обозначенным восстановленным снимком, без выдуманных дат и авторов.

Пользователь подтвердил проверку новых исправлений Num5 и ранее отправленных функций
в игре. Автоматические результаты и сценарии повторной проверки описаны в
`docs/maintenance/VERIFICATION.md`; подтверждение пользователя отмечено отдельно.
