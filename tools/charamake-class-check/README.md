# Проверка описаний стартовых классов

Запуск из корня проекта:

```powershell
dotnet run --project tools/charamake-class-check/CharaMakeClassCheck.csproj -c Release -- "ПУТЬ-К-ИГРЕ/game/sqpack" "artifacts/logs/charamake-class-check.json"
```

Инструмент вызывает настоящий код плагина для восьми стартовых классов,
четырёх языков клиента и русского/английского режима плагина. Проверяет
оба набора оружия: показной из CharaMakeClassEquip и реальные полные модели
из журнала 6.08.82 от 30 сентября 2026, 23:13. Эти модели заданы отдельно
от таблицы, которую использует плагин. Всего 128 проверок вместо прежних 64.
Проверяет имя класса, соответствие строке Lobby и точное
совпадение исходного текста с её полем Unknown1. В установленной таблице Lobby строки
178, 180, 182, 184, 186, 188, 190 и 192 содержат заголовок в Text и полное
описание в Unknown1; поле Text общего окна справки для этого не требуется.

Реальное стартовое оружие определяется через ClassJob.ItemStartingWeaponMainHand
и Item.ModelMain. Проверяются все части модели, кроме красителей: совпадения
одного номера основы недостаточно. Неизвестная или неоднозначная модель не
получает описание наугад.

Названия и восемь полных описаний берутся из встроенных русских справочников
только в русском режиме. Описание применяется при совпадении класса и всего
английского исходного текста с установленной таблицей. Для других языков
и изменившегося источника сохраняется текст игры. Проверка требует русского
описания без английских фрагментов на всех четырёх языках клиента; именно
проверки имени было недостаточно в 6.08.83.
Проверка по чистым файлам sqpack не подтверждает загрузку XIV Rus, задержки
смены модели, состояние окон или речь NVDA в работающей игре.
