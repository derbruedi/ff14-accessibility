# Русские описания для речи

Справочник находится внутри DLL, не требует соединения с интернетом во время игры
и применяется только при `Loc.IsRussian`. Источник — закреплённый снимок
[XIV Rus](https://github.com/xivrus/xiv_ru_weblate/tree/6a2733af6df0f86b133bcbf61c553dfacf80ec2d).
Собственные дополнения и исправления явно сохранены в `local-game-overrides.json`
и `overrides.json`. Версия игры указана внутри первого файла. Это переводы проекта,
а не утверждение, что команда XIV Rus проверила эти дополнения.

Каждая запись содержит исходную английскую строку и русский перевод. Перед
озвучкой исходник побайтово сравнивается с английской таблицей установленной игры.
После изменения характеристик в патче старый перевод не применяется: остаётся
актуальный игровой текст. Формулы и условные части текста сохраняются в формате
игры и вычисляются через `ISeStringEvaluator` при каждом чтении. Нельзя заменять
управляющие вставки простым удалением тегов: так теряются числа и условия.

## Обновление и воспроизведение

Нужен Python 3.10 или новее. Запускать из корня проекта:

```powershell
python tools/russian-descriptions/generate.py --download
python -m unittest discover -s tools/russian-descriptions -p test_generate.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test-Local.ps1
```

`--download` получает только 18 файлов XLIFF закреплённого снимка. Без этого флага
используется локальная копия в `.local/russian-descriptions`. Результат воспроизводим:
gzip не содержит текущую дату. Хеши исходников, результат и список пропусков
записываются в `docs/maintenance/russian-descriptions-coverage.json`.
Для нового снимка передать точный `--revision`; прежние локальные переводы также
следует сверить с новой игрой, а не просто переносить старые числовые значения.

Проверка по установленным файлам игры, без её запуска:

```powershell
$dalamudPath = Join-Path $env:APPDATA 'XIVLauncher\addon\Hooks\dev'
dotnet run --project tools/russian-descriptions/Verify.csproj -c Release "-p:DALAMUD_HOME=$dalamudPath" -- 'ПОЛНЫЙ_ПУТЬ_К_GAME\sqpack' 'FF14Accessibility\Resources\RussianDescriptions.json.gz' 'artifacts\logs\russian-descriptions-game-coverage.json'
```

Проверяется формат всех исходных и переведённых строк, включая вложенные условия,
а затем совпадение каждой непустой строки выбранных таблиц с установленной игрой.
Пропуски и расхождения дают ненулевой код завершения. Отдельный `.gaps.json`
содержит проблемные строки для разбора. Не выдавать число строк за количество
доступных игроку умений: таблицы включают старые и служебные записи.

`ReadOnlySeString.Validate()` в проверенной версии Lumina всегда возвращает false,
даже для обычной строки. Поэтому проверяющий инструмент использует чтение отдельных
фрагментов и рекурсивную проверку выражений. Это проверка формата и источника,
а не проверка фактической речи или всех ветвей формул в запущенной игре.

Пустое описание в самой игре остаётся пустым. С 6.08.70 известные английские
названия действий и эффектов внутри принятого русского описания заменяются
словарём `RussianDescriptionTerms` после вычисления игровых формул. Сначала
проверяется самое длинное название, затем границы слов; числа и команды остаются
целыми. Словарь создаётся `tools/russian-localization/generate_game_text.py`.
Неизвестные собственные имена сохраняют исходное написание.

С 6.08.78 включены GeneralAction, PetAction и MainCommand: 183 описания.
26 дополнений и уточнений перевода сохранены в overrides.json. Четыре строки
MainCommand содержат лишь отметку об отсутствии описания; новые свойства
для них не выдумываются.
