# Проверка русских классов и мест экипировки

Из корня проекта при установленной игре и зависимостях Dalamud:

```powershell
dotnet run --project tools/equipment-speech/Verify.csproj -c Release -- 'ПУТЬ_К_GAME\sqpack' 'artifacts/logs/equipment-speech.json'
```

Проверка вызывает код плагина с настоящими таблицами установленной игры,
без запуска FFXIV и без обращения к состоянию персонажа. Отсутствующие файлы
или несовпавшие ожидания завершают её с ошибкой, а не пропуском.

Проверяются все непустые категории классов, все именованные предметы,
длинные списки профессий, язык клиента, переключение языка плагина,
два альтернативных места для кольца, заблокированные места для оружия
и комплектов одежды. Дополнительно проверяются общие методы названий
инвентаря, магазинов и сравнения, сохранение чистого имени для поиска,
неизвестные названия; неоднозначные проверяются при наличии таких строк
в таблице игры, их отдельный счётчик сохраняется в отчёте.

В отчёте сохраняются версия игры, счётчики и ожидаемые произносимые строки.
С 6.08.115 проверяются также полные параметры 12 вещей из журнала арсенала,
включая HQ, и три ступени магазина великой компании при наличии шести
ступеней в общей таблице рангов. Используется тот же сборщик подписи арсенала;
состояние живого персонажа при этом не проверяется.
Эта проверка не доказывает правильное определение выбранного предмета
в живом окне, доступность вещи текущему персонажу или фактическую речь NVDA.
