# Русский установщик FF14 Accessibility

Версия 1.3.0 разделяет установку и удаление перевода игры и языка мода:
«Установить русификацию игры», «Установить русификацию мода»,
«Удалить русификацию игры» и «Удалить русификацию мода».
Также доступны «Полностью удалить мод» и «Полностью удалить мод и русификацию игры».
Удаление работает без сети
при закрытых игре и XIVLauncher. Мод удаляется вместе с личными клавишами,
настройками, маршрутами, журналами, всеми установленными версиями и записями
Dalamud. Для XIV Rus очищаются все найденные копии, кеш, коллекции, база и
архивы настроек Penumbra. Резервные записи Dalamud также очищаются, чтобы
настройки не восстановились при следующем входе. Удаление русификации игры
сохраняет язык мода. Удаление русификации мода задаёт английский язык сообщений
и речи, сохраняя мод, личные клавиши, маршруты и XIV Rus.
Другие моды, Penumbra и vnavmesh сохраняются.
Скачанные вручную EXE и архивы вне папок установки пользователь удаляет сам.
Перед началом появляется подтверждение. Отмена до записи сохраняет все данные;
при ошибке записи прежние файлы возвращаются. Недоступные остатки показываются
в окне и не считаются завершённым удалением. После полного удаления журнал остаётся
только в окне, чтобы не создать заново очищенную папку журналов установщика.

Один файл `FF14AccessibilityInstaller.exe` для Windows x64. .NET уже включён.
Скачивает стабильную русскую сборку только из
[релизов владельца](https://github.com/pitpamyati-netizen/ff14-accessibility/releases/latest).

При открытии проверяет версии, ничего не устанавливая. Кнопка
«Установить / обновить мод» устанавливает отсутствующий мод или более новую
версию. Повторный запуск проверяет комплектность и включение в Dalamud.
Версия читается из установленной DLL; откат на более старую не производится.

Журнал — обычное многострочное поле Windows, доступное скринридеру.
Сообщения разделены пустыми строками, текст увеличен, у каждой операции есть
название. Время сообщений скрыто; стандартные личные пути заменены обозначениями
%APPDATA%, %LOCALAPPDATA% и %USERPROFILE%. Сохранённый файл содержит тот же текст.
Tab и Shift+Tab переключают журнал и кнопки; Enter/пробел нажимают кнопку.
Стрелки, Ctrl+Home и Ctrl+End позволяют читать журнал, Ctrl+C копирует выделенное.
Во время работы доступна отмена; начавшаяся запись сначала безопасно завершается.

Нужны установленный XIVLauncher, настроенный Dalamud и один состоявшийся вход
в игру через него. Папка определяется как `%APPDATA%/XIVLauncher`.
Перед записью должны быть закрыты игра и XIVLauncher. Обычная кнопка установки
сохраняет пользовательские настройки; русский язык можно выбрать `/acc lang ru`.

## Русификация игры

Кнопка **«Установить русификацию игры»** выполняет следующие действия:

1. Находит Penumbra в каталоге Dalamud, стандартной папке или зарегистрированном
   пользователем месте. Включает найденную копию; отсутствующую скачивает из
   [официального каталога](https://raw.githubusercontent.com/xivdev/Penumbra/master/repo.json)
   и регистрирует в Dalamud. Каталоговая установка сохраняется без второй копии.
2. Проверяет включение Penumbra и совместимость с установленной Dalamud.
   FF14Accessibility для этого действия не требуется; его язык и файлы сохраняются.
3. Проверяет последний стабильный [XIV Rus](https://xivrus.ru/download).
   Использует полный установленный перевод той же или более новой версии.
   Архив ищет рядом с EXE, в текущей папке, в «Загрузках» Windows, включая
   перенесённую папку, и в собственном кэше. Найденный архив используется только
   при совпадении SHA-256 с официальным выпуском; остальные файлы сохраняются.
   Если нужного архива нет, скачивает его автоматически.
4. Сам подготавливает отсутствующие настройки Penumbra. Отдельно входить в мир
   и выходить ради создания этих файлов больше не требуется. Существующие
   коллекции, назначения персонажей и настройки других модов сохраняются.
5. Использует существующую папку модов или создаёт
   `%APPDATA%/XIVLauncher/PenumbraMods`. Распаковывает перевод, включает моды
   Penumbra и XIV Rus во всех существующих коллекциях. Пустые назначения общей
   коллекции и интерфейса заменяет существующей коллекцией Default. Остальные
   назначения и параметры установленных модов сохраняет.

Перевод рассчитан на **английский язык клиента FFXIV**. Установщик не меняет язык
клиента. Текущий XIV Rus скачивается у авторов и не встроен в EXE: выпуск 1.19.1
занимает около 354 МБ при скачивании и 3,8 ГБ после распаковки. Для обновления
нужно дополнительное место, поскольку старая папка сохраняется. Привязку выпуска
к патчу игры смотрите на странице XIV Rus; установщик не определяет совместимость
самого перевода с установленным патчем FFXIV автоматически.

Настройки меняются с резервной копией и восстановлением при обычной ошибке записи.
Прежняя папка перевода сохраняется рядом с корнем модов, в папке с суффиксом
`-backup`, и не смешивается с новой. Внутри копии `restore-map.json` указывает
исходные пути настроек. Несколько копий Penumbra/XIV Rus, неизвестный формат
настроек, нехватка места и несовпадение контрольной суммы останавливают этот шаг.
Завершённые шаги (например, установка Penumbra) сохраняются и отражаются в журнале.
Нажатие этой кнопки не устанавливает vnavmesh; её предлагает обычная кнопка установки.

Кнопка **«Установить русификацию мода»** устанавливает или обновляет FF14Accessibility
и включает русский язык сообщений и речи. Она сохраняет личные клавиши, громкость
и настройку перевода предметов и умений. Penumbra, XIV Rus и vnavmesh для этого
действия не устанавливаются. Изменения языка записываются также в сохранённые
настройки Dalamud, чтобы язык не вернулся к прежнему при следующем запуске.

Проверка настоящих загрузок, остановки перед первым входом, продолжения и повтора
в отдельной новой папке. Настройки создаёт сам установщик; их дополнительно
читают настоящие типы установленной Dalamud и скачанной Penumbra:

```powershell
dotnet run --project tools/installer-check/InstallerCheck.csproj -c Release -- artifacts/russification-check-NEW --translation
```

Если GitHub временно ограничивает анонимные запросы, проверочный инструмент
принимает третьим аргументом папку с неизменёнными ответами API:
`accessibility-release.json` и `xivrus-release.json`. Их можно получить
чтением `gh api repos/ВЛАДЕЛЕЦ/ПРОЕКТ/releases/latest` для двух источников выше.
Это только способ повторной проверки; готовый EXE использует обычный HTTPS.
Инструмент явно отмечает такие ответы в журнале. Архивы по-прежнему проверяются
по контрольным суммам, а не подменяются тестовыми данными.

Это проверка файлов, а не запуск игры. Загрузка Penumbra, русский текст в FFXIV
и речь NVDA требуют отдельной проверки в игре. Для первичного создания основного
файла поддерживается Penumbra 1.7.2; существующий формат 100 и старый формат 15
обрабатываются с сохранением личных настроек. Неизвестный формат вызывает объяснение ошибки.

После записи установщик повторно проверяет автозагрузку и совпадение записей
Penumbra в профилях Dalamud. Он исправляет различия в написании пути DLL,
восстанавливает включение каталога для каталоговой копии и обнаруживает
безопасный режим Dalamud, при котором плагины не запускаются.
Журнал автоматически сохраняется в `%LOCALAPPDATA%/FF14AccessibilityInstaller/logs`.
Эта папка указана в окне; при сообщении об ошибке приложите нужный файл.

Если vnavmesh отсутствует, после установки мода появляется обычный вопрос «Да/Нет».
При согласии она скачивается из [каталога разработчика](https://puni.sh/api/repository/veyn),
проверяются имя, DLL, версия и совместимость с Dalamud API из манифеста мода.
Каталог разработчика не публикует SHA-256 vnavmesh: здесь проверяется HTTPS,
структура и версия архива. Для русской сборки дополнительно обязателен SHA-256
из GitHub или `SHA256SUMS.txt`.
Наличие vnavmesh проверяется в devPlugins, зарегистрированных путях и installedPlugins.
Уже установленная vnavmesh сохраняется; этот EXE не обновляет её автоматически.

Перед заменой файлов сохраняется вся прежняя папка плагина и настройки Dalamud
в `%APPDATA%/XIVLauncher/installer-backups/ДАТА-ID`. Для зарегистрированной папки
вне XIVLauncher копия лежит рядом, в `.FF14Accessibility-backups`.
Журнал сообщает о сохранении копии. При обычной ошибке записи выполняется восстановление.
Аварийное выключение компьютера во время записи требует проверки резервной копии.
Архив не может записывать файлы вне временной папки; скрипты из ZIP не выполняются.
Неизвестная структура настроек и несколько установленных копий вызывают отказ,
а не выбор случайной копии. Установка FF14Accessibility через каталог Dalamud
требует сначала удалить каталоговую копию с сохранением настроек.

Сборка из корня исходников:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Installer.ps1
dotnet test tests/Installer.Tests/Installer.Tests.csproj -c Release
```

Результат и отчёт: `artifacts/installer/ДАТА/` и `artifacts/installer-build-info.json`.
Исходники установщика с тестами и инструментом проверки выпускаются отдельным
`FF14AccessibilityInstaller-1.3.0-source.zip`; старый Source code релиза 6.08.73
сам по себе этих новых файлов не содержит. В ZIP готового мода исходников нет.

Проверка настоящих загрузок и двух установок в отдельную новую папку:

```powershell
dotnet run --project tools/installer-check/InstallerCheck.csproj -c Release -- artifacts/installer-check-NEW
```

Она использует настоящий сервер и проверяет, что рабочая установка пользователя
не изменилась. Она не запускает игру и не подтверждает речь скринридера.
Старый DE/EN-установщик в родительской папке сохранён для совместимости с upstream.
