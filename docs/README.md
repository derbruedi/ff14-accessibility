## Справочные материалы автора

Английские и немецкие документы об устройстве интерфейса, геймпаде, игровых
данных и переводах сохранены для разработки. Общие руководства по созданию
модов, Unity, MelonLoader и BepInEx описывают другие проекты и не являются
инструкцией установки FF14 Accessibility. FFXIV использует Dalamud.

Текущая пользовательская инструкция всегда находится в [installation.md](installation.md).
Сведения о русской ветке и её проверках — в `maintenance/`.
