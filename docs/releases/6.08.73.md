## Установка и русификация

Нужны Windows x64, FFXIV, XIVLauncher с Dalamud API 15 и скринридер.
При первой настройке XIVLauncher один раз войдите в игру с включённым Dalamud.

1. Закройте FFXIV и XIVLauncher, скачайте и запустите EXE 1.1.2.
2. Для установки с русским переводом нажмите **«Русифицировать игру и мод»**
   и дождитесь завершения.
3. Запустите FFXIV через XIVLauncher с **английским языком клиента**.

Кнопка находит и включает Penumbra либо устанавливает её, подготавливает
FF14Accessibility и включает русский язык его сообщений. Актуальный XIV Rus
используется повторно или скачивается с официального источника; скачанный архив
проверяется по контрольной сумме. Недостающие настройки Penumbra создаются
автоматически. Личные настройки сохраняются, перед заменой создаётся резервная копия.

В **1.1.2** русификация также включает ожидание загрузки плагинов перед запуском
игры. Это нужно, чтобы Penumbra успевала загрузить перевод ранних окон,
в том числе очереди входа и настроек. Если перевод уже установлен, снова
нажмите **«Русифицировать игру и мод»**, затем полностью запустите игру заново.

Для установки только мода доступности выберите **«Установить / обновить мод»**.
При необходимости согласитесь на установку vnavmesh для маршрутов.
Русский язык сообщений можно выбрать командой `/acc lang ru`.
Для следующего обновления снова запустите EXE. Более новая установленная
версия мода не заменяется старой. Журнал сохраняется автоматически;
его путь и версия установщика указаны в окне.

Сам XIV Rus не встроен в EXE. Для его скачивания, распаковки и резервной копии
нужно свободное место на диске. Соответствие перевода патчу FFXIV проверяйте
на [странице XIV Rus](https://xivrus.ru/download): установщик не определяет
его автоматически. Версия игрового плагина остаётся **6.08.73**.

## Ручная установка

Распакуйте ZIP мода, закройте игру и лаунчер, сохраните копию прежней папки мода.
Скопируйте всё содержимое `plugin` в
`%APPDATA%\XIVLauncher\devPlugins\FF14Accessibility`.
При первой установке добавьте полный путь к `FF14Accessibility.dll` в
Dalamud Settings → Experimental → Dev Plugin Locations, затем включите плагин
и его загрузку при запуске. vnavmesh для этого способа устанавливается отдельно.
Этот ZIP содержит игровой плагин; изменения русификации в установщике 1.1.2
применяются через EXE.

## Что нового в моде 6.08.73

- `FFXIV_Keybinds.txt` больше не создаётся на рабочем столе при входе в игру.
  Список клавиш сохраняется по команде `/acc keys`.
- Подходящие классы и места экипировки читаются по-русски.
- При застревании у края подъёма добавлен поиск короткого подхода сбоку.
  Повторное Num3 отменяет движение; автоматических прыжков нет.
- Расширены русские названия и описания предметов, умений и эффектов,
  переведены 3 813 фраз внешности, используемых плагином. Перевод встроен.

## Проверки

Для 1.1.2 прошли сборка, упаковка и 163 автоматических теста, из них 77 —
проверки установщика. Первая установка, повтор и восстановление отсутствующих
настроек проверены с настоящими Penumbra и XIV Rus в отдельной папке.
Сборка из отдельного ZIP исходников дала тот же EXE; повторная сборка перед
публикацией также побайтово совпала с выбранной версией.

Пользователь выбрал эту версию по её работе. Автоматические проверки отдельно
не подтверждают перевод каждой строки в FFXIV, речь NVDA и переходы клавишей Tab
в окне установщика. Во время публикации игра не запускалась.

`installer-SHA256SUMS.txt` содержит контрольные суммы текущего EXE и его исходников.
`SHA256SUMS.txt` относится к архиву игрового плагина и DLL внутри него.
