# FF14 Accessibility 6.08.84

Подготовленная сборка от 1 октября 2026. Исходники предназначены для рабочей
ветки нашего форка; публикация отдельного выпуска GitHub не выполнялась.

Проверены изменения начиная с 6.08.78: таблицы и навыки, чтение классов,
клавиша следования, характеристики и новая проверка пути между этажами.
Разбор причин и границы проверки — в
[отчёте](../maintenance/REVIEW_FROM_6.08.78.md).

При создании персонажа теперь встроенно читаются полные русские описания
всех восьми стартовых классов. Перевод связан с классом и точным английским
источником; при изменении таблицы сохраняется текст игры. Речь не зависит
от наличия русского перевода этих строк через XIV Rus. Название, отложенное
описание и повтор Ctrl+F10 относятся к текущему классу.

Новая проверка навигации больше не требует, чтобы каждый участок земли
совпадал с прямой линией между редкими точками маршрута. Проверяется настоящая
поверхность вдоль пути и её соединение с нужным этажом. Обычные подъёмы и спуски
допускаются; путь через пустоту и неподтверждённый скачок этажа отклоняются.
Повторный расчёт vnavmesh вызывает ограниченную повторную проверку вместо
немедленного завершения. Продвижение по обходу учитывается даже при удалении
от цели. Остановка отменяет поиск, поздний ответ не запускает движение.

Высота живого NPC не заменяется высотой соседнего этажа. Приблизительная
высота картографической метки не принимается за точный этаж. Начало движения
к живой цели сбрасывает признаки предыдущей метки и перехода зоны.
Контроль движения и остановки продолжает работать при открытом чтении таблиц
и вводе количества покупки.

При листании объектов Page Up/Page Down не выполняются одновременно штатные
действия этих клавиш. Num3 также поглощается при управлении навигацией.
После принятого игрой выбора убирается старая временная цель. Если игра не
может выбрать объект, предупреждение сохраняется, а его позиция доступна
для подхода. Первое Page Up выбирает последний пункт списка.

Release собран без ошибок и предупреждений. Пройдены 435 тестов без
пропусков и десять проверок запрета выпуска. По игровым таблицам выполнены
128 проверок классов, 23 проверки навыков и сверка 93 элементов окна C.
В ZIP 141 файл; все записи и DLL совпадают по SHA-256.

Проверки по игровым таблицам и автоматические тесты описаны в
[VERIFICATION.md](../maintenance/VERIFICATION.md). Новая сборка агентом
в запущенной FFXIV не проверялась. Особенно нужны обычный длинный маршрут,
подъём к Браконьеру Зверолапых в территории 153, остановка Num3, смена зоны
и принятие цели после Page Up/Page Down. Нельзя считать проверкой игры
успешную сборку, тесты или чтение файлов sqpack.

ZIP без исходников содержит папку plugin, русскую инструкцию и лицензии.
Установщик остаётся версии 1.1.2 и скачивает последний опубликованный выпуск;
пока 6.08.84 не опубликована, для неё нужна папка plugin из подготовленного ZIP.
