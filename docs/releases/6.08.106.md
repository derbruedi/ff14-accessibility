# FF14 Accessibility 6.08.106 — совместимость с Project Prima

При использовании Project Prima через Harmonia плагин сначала читает перевод
из самой игры. Названия и описания предметов, умений, эффектов, классов, мест,
противников, заданий и питомцев больше не перекрываются прежними переводами
плагина, когда у игры есть переведённая строка.

Переведённые названия распознаются в магазинах и меню умений. Сохраняются
настоящие номера предметов, типы боевых/ремесленных действий и проверка
выбранного рецепта. Совпадающие названия с разными описаниями не приводят
к произвольному выбору; используется описание выбранной игровой панели.
Учитывается текущий результат Harmonia, включая отключённые разделы и
исключения. Файлы и настройки русификатора не изменяются.

`/acc translate off` выключает собственные переводы плагина. Текст,
переведённый в игре, продолжает читаться в варианте русификатора. Новые
описания сохраняют игровые вставки и проходят штатное вычисление текста;
прежние замены терминов к ним не применяются.

В выпуск также входят исправления штатного подтверждения кнопками Num0/Insert
и Enter, контекстная справка, чтение ячеек осмотра и распознавание заданий Prima.

Проверены данные установленной Prima 2026.10.04.0002 для игры
2026.09.15.0000.0000: 853 591 переведённая строка, 402 094 чтения именованных
полей, 99 914 вариантов названий предметов, 57 584 варианта названий экипировки,
42 меню действий/пассивных навыков и 5 280 названий заданий. Отдельно проверены
46 061 поле дополнительных читателей и два неоднозначных меню.
Эти проверки используют игровые таблицы и локальный пакет; запуск FFXIV,
чтение памяти её процесса, динамические числа в живой игре и речь NVDA/Tolk
ещё не проверены. Подробности — в [отчёте проверок](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/maintenance/VERIFICATION.md)
и [описании совместимости](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/v6.08.106/docs/harmonia-compatibility.md).

Окончательная сборка прошла без ошибок и предупреждений; все 996 тестов
проекта прошли без пропусков. ZIP содержит 141 проверенный файл без исходников.

Файлы выпуска:

- `FF14AccessibilityInstaller.exe` — автоматическая установка и обновление,
  установщик 1.3.0.
- `FF14Accessibility-6.08.106-RU-no-source.zip` — ручная установка, без исходников.
- `SHA256SUMS.txt` — контрольные суммы готовых файлов и DLL.
- `FF14AccessibilityInstaller-1.3.0-source.zip` — исходники установщика.
- Автоматические архивы GitHub Source code — исходники плагина по метке выпуска.

Обновите плагин при закрытых FFXIV и XIVLauncher. После обновления выполните
полный перезапуск игры и используйте `/acc lang ru`. Установщик обновляет
FF14Accessibility; его отдельная кнопка перевода игры устанавливает прежний
XIV Rus/Penumbra. Для Project Prima используется уже установленная Harmonia.
