# FF14 Accessibility 6.08.108 — общий поиск входов между зонами

Исправлено повторение «Обновление завета в другой зоне, и я не нахожу туда
перехода». Из Старой Гридании маршрут ведёт к охраннику Круга Лотоса.
Из гостиницы первый участок ведёт к настоящей двери выхода, затем через
Новую и Старую Гриданию к охраннику. Рядом нажмите Num0 и подтвердите
переход в игре; после смены зоны снова выберите задание и нажмите Num3.

Общий поиск теперь учитывает входы через NPC и двери, в том числе без
значков карты и без исходной строки в таблице расположения. Источником
служат проверенные связи игры и реальные объекты в исходной зоне.
Выбор объекта относится к первому участку маршрута, даже если цель дальше.
Обычные пешие границы сохраняют приоритет перед необязательным транспортом.
Условия, возможную плату и подтверждение перехода определяет игра.
Неизвестные сценарные входы без проверенной связи не угадываются.

На данных установленной игры просмотрена 1 231 карта: проверен 61 вход
на 27 исходных картах и 192 утверждения. Добавлены 16 тестов против
повторения, включая выход из гостиницы и длинный маршрут с циклами.
Полная проверка: 1 028 тестов без пропусков, сборка без ошибок и
предупреждений, ZIP — 141 проверенный файл без исходников. Подробности в [отчёте](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/maintenance/VERIFICATION.md).
Живое движение, подтверждения, переходы зон и NVDA/Tolk ещё не проверены.

Сохранены чтение Project Prima, русская речь и прежние исправления.
Обновляется существующая запись выпуска 6.08.107; старая метка сохраняется.
Установщик 1.3.0 и его исходники остаются прежними.

Файлы выпуска:

- `FF14AccessibilityInstaller.exe` — установка и обновление, версия 1.3.0.
- `FF14Accessibility-6.08.108-RU-no-source.zip` — плагин без исходников.
- `SHA256SUMS.txt` — контрольные суммы.
- `FF14AccessibilityInstaller-1.3.0-source.zip` — исходники установщика.
- GitHub Source code — исходники плагина по метке v6.08.108.

Обновляйте при закрытых FFXIV и XIVLauncher, затем полностью перезапустите игру.
