# FF14 Accessibility 6.08.110 — пешие переходы на высоте дороги

Исправлен случай «Переход в Нижняя Ла-Носкея: 13 метров, южнее».
Журнал установленной 6.08.109 показал, что оба режима навигации получали
цель почти на 20 метров выше дороги. Поиск проверял середину высокого
объёма перехода и затем принимал неподтверждённую точку.

Теперь ручное наведение и автоматическое движение используют высоту
дороги, проверенную в пределах реальной области перехода. Точка остаётся
внутри этой области; повторный широкий поиск не сдвигает её за границу.
Это общее исправление пеших переходов, включая первый участок маршрута
задания, без отдельной таблицы координат для Ла-Носкеи. Проверяются соседние
проходы и другие выходы в ту же зону; при полном отказе движение не начинается.
Прежний механизм движения, измеренные обходы автора и короткий последний
шаг через границу сохранены.

Автоматически проверены повреждённые и неподдерживаемые объёмы, разные
высоты, закрытый проход, соседний выход, конечное положение внутри границы
и общий выбор цели для обоих режимов движения. На установленных игровых
данных просмотрены 125 объёмов пеших переходов, из них 68 высоких;
проверка входов и маршрутов прошла 2 687 утверждений по 1 231 карте.
Ответ сетки для записанного сбоя воспроизведён по журналу. Это проверка
вычислений и данных; движение, загрузка зоны и речь FFXIV/NVDA/Tolk
в новой версии ещё не проверены в игре. Полная Verify-Local прошла:
1 086 тестов без пропусков, Release без ошибок и предупреждений,
11 проверок защиты упаковки. ZIP содержит 141 файл без исходников;
состав и контрольные суммы сверены.

Для обновления используйте `FF14AccessibilityInstaller.exe`.
Для ручной установки скачайте `FF14Accessibility-6.08.110-RU-no-source.zip`:
в нём папка `plugin`, инструкция и лицензии, без исходников, EXE и скриптов.
Исходники плагина доступны по метке выпуска. Отдельный архив
`FF14AccessibilityInstaller-1.3.0-source.zip` содержит исходники установщика.
Контрольные суммы опубликованы в `SHA256SUMS.txt`.

После обновления повторите переход из Средней в Нижнюю Ла-Носкею:
выберите его в списке мест, проверьте Ctrl+Num3 при ручном движении,
затем Num3 для автоматического движения. Проверьте фактическую загрузку
Нижней Ла-Носкеи, остановку, обратный выход и речь скринридера.
