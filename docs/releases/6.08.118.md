# FF14 Accessibility 6.08.118 — поддержка обновлённой игры

Для обновлённой игры 2026.10.06.0000.0000 появился обычный выпуск
Dalamud 15.0.3.7. Плагин пересобран с его библиотеками; уровень API остаётся 15.

Исправлено чтение типа столбца при получении русских текстов игры
через Harmonia / Prima: используется новое поле ColumnType.
Проверка совпадения типов, смещений, языка и вида строк сохранена.
Остальные игровые функции и алгоритмы навигации не менялись.

Release собран без ошибок и предупреждений. Все 1 187 тестов в семи
проектах прошли без пропусков, 12 проверок защиты упаковки и защита
навигации также прошли. Игровой ZIP содержит 141 файл; все записи
сверены по SHA-256, исходников и установочных скриптов внутри нет.

Для автоматической установки или обновления скачайте
`FF14AccessibilityInstaller.exe`. Для ручной установки используйте
`FF14Accessibility-6.08.118-RU-no-source.zip`: внутри находятся папка
`plugin`, инструкция и лицензии. `SHA256SUMS.txt` содержит контрольные
суммы; `FF14AccessibilityInstaller-1.3.0-source.zip` нужен разработчикам
установщика, для установки готового мода он не требуется.

Обновите Dalamud штатным способом через XIVLauncher. Перед заменой
плагина закройте игру и лаунчер; сохраните прежние файлы и настройки.
Подробная инструкция включена в архив и доступна в
[README-RU.txt](../../README-RU.txt).

Загрузка плагина, речь NVDA/Tolk, клавиатура, выбор цели и оба режима
навигации в обновлённой FFXIV ещё не проверены. Сборка и автоматические
проверки не подтверждают эти игровые сценарии.
Подробные результаты — в [VERIFICATION.md](../maintenance/VERIFICATION.md).
