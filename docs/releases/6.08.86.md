# FF14 Accessibility 6.08.86 — проверка версий 73–78 и исправления

Проверены исходники функций версий 6.08.73–6.08.78, их связь с клавишами,
штатными действиями игры и источниками данных. Выпуск включает также
подготовленные ранее изменения 6.08.84 и 6.08.85.

- Alt+F3 больше не теряет контроль при открытии режима чтения или другого
  меню плагина. Смена исходного окна инвентаря и потеря фокуса игры прекращают
  обработку; старая очередь не возобновляется. Перенос использует меню игры,
  проверяет конкретный предмет и оба изменения инвентаря.
- В редакторе количества и чтении таблиц функциональные клавиши и знаки
  не запускают команды игры. Enter в редакторе задаёт количество;
  покупку по-прежнему подтверждает игрок. Справка и остановка речи доступны.
  Num5 обновляет таблицу также при выключенном NumLock.
- Неполный список рецепта больше не скрывает нужный материал. Все материалы
  и количества проверяются по собственной записи рецепта. При несовпадении
  читаются поля окна; неизвестные числа не превращаются в ноль.
  Кристаллы названы, их запас читается отдельно по правильному предмету.
- Ошибки ответа Penumbra не считаются признаком выключенного мода.
  Неизвестные записи не переключаются; сохранённый список восстановления остаётся.
- `/acc translate off` отключает русский перевод предметов и умений в речи,
  `/acc translate on` возвращает его. Выбор сохраняется после перезапуска,
  подсказки и личные клавиши сохраняются. Видимый перевод XIV Rus/Penumbra
  управляется отдельно.
- Сохранены русские описания восьми стартовых классов, исправления движения
  по подъёмам и пересчёта пути, настоящая высота NPC и выбор объектов
  Page Up/Page Down из 6.08.84.

## Скачать и обновить

- **FF14AccessibilityInstaller.exe** — русский автоматический установщик 1.1.2.
  Закройте игру и XIVLauncher, запустите EXE и выберите обновление мода.
  Он получает текущий стабильный выпуск и сохраняет резервную копию.
- **FF14Accessibility-6.08.86-RU-no-source.zip** — ручная установка.
  Внутри `plugin`, инструкция и лицензии, без исходников, EXE и скриптов.
  При закрытой игре сохраните прежнюю папку и скопируйте всё содержимое `plugin`.
- **SHA256SUMS.txt** — контрольные суммы архива, DLL и установщика.
- **FF14AccessibilityInstaller-1.1.2-source.zip** — отдельные исходники установщика.
  GitHub Source code содержит исходники проекта по метке выпуска.

Нужны Windows x64, FFXIV с совместимым Dalamud API 15 и скринридер.
Подробности — в [инструкции](../installation.md).

## Что проверено

Release собран без ошибок и предупреждений. Пройдены 473 обязательных теста
без пропусков и десять сценариев запрета упаковки без актуальных результатов.
Дополнительно сверены 13 892 рецепта, семь разделов Num+,
структура окна C, меню P и переключатели перевода по установленным файлам игры.
Все 25 806 пар русских описаний совпали с источником; управляющие вставки сохранены.
Состав ZIP и все контрольные суммы проверены.

Полный разбор — [отчёт по версиям 73–78](../maintenance/REVIEW_6.08.73-78.md),
числа и результаты общей проверки — [VERIFICATION.md](../maintenance/VERIFICATION.md).
Установка и проверка этой сборки в работающей FFXIV, речь NVDA/Tolk
и реальные перенос/покупка агентом не выполнялись.
