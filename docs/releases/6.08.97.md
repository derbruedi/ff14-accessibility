# FF14 Accessibility 6.08.97 — системные настройки звука

В системных настройках FFXIV каждый ползунок теперь называет канал и текущий
процент: общая громкость, музыка, звуковые эффекты, голоса персонажей,
системные и окружающие звуки, музыкальные инструменты, эффекты своего
персонажа, группы и других игроков. При регулировке название сохраняется
в речи. Подпись берётся из строки самого ползунка; общий заголовок страницы
больше не подставляется вместо названия канала.

Для точного значения выберите ползунок, нажмите **Ctrl+Enter**, введите число
от **0 до 100** и нажмите **Enter**. Первое число заменяет прежнее значение;
Backspace исправляет ввод, Delete очищает его, Escape отменяет ввод.
Ноль выключает громкость выбранного канала. После подтверждения плагин
проверяет значение в штатном ползунке игры. Для сохранения настроек нажмите
штатную кнопку **«Применить»**. Обычное управление ползунками также сохранено.

При смене ползунка, страницы, окна или значения извне старый ввод отменяется.
Временная потеря фокуса и повторное открытие не сохраняют старый адрес
ползунка для чтения. Настройки плагина и личные клавиши не сбрасываются.

С последнего опубликованного выпуска 6.08.93 также включены исправления
локальных 6.08.95–6.08.96: чтение выбранных ячеек инвентаря и арсенала после
сортировки, названия фильтров арсенала, выбор и взаимодействие с конкретным
доступным объектом задания. Отдельная незавершённая работа над автоповоротом
при AoE в этот выпуск не включена.

## Установка

- **FF14AccessibilityInstaller.exe** — автоматическая установка и обновление.
- **FF14Accessibility-6.08.97-RU-no-source.zip** — готовый плагин, инструкция
  и лицензии. Исходников, PDB и скриптов установки в этом ZIP нет.
- **SHA256SUMS.txt** — контрольные суммы готовых файлов.
- **FF14AccessibilityInstaller-1.1.2-source.zip** — отдельные исходники установщика.

Закройте FFXIV и XIVLauncher перед обновлением. После установки запустите
игру обычным способом. Совместимость: Dalamud API 15.

## Проверка

Release собран без ошибок и предупреждений, все 685 тестов пройдены без пропусков.
ZIP из 141 файла и установленный плагин сверены по SHA-256. Настройки сохранены.
Новые автоматические проверки охватывают все десять подписей по структуре
установленной игры, русский и другие языки, точные значения 0/37/100,
неверный ввод, смену окна/ползунка и неподтверждённое изменение.
Это не проверка живой речи и нажатий в FFXIV/NVDA/Tolk: после обновления они
ещё требуют проверки в игре. Подробные результаты — в `VERIFICATION.md`.
