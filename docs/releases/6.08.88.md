# FF14 Accessibility 6.08.88 — общая защита автонавигации

Проверена вся цепочка автоматического движения: пешие назначения, обходы,
записанные пути, границы зон, следование, полёт, посадка и остановка с клавиатуры.
Исправления применяются к общим правилам движения, включая обычную ровную карту
и отметки, у которых высота известна приблизительно.

- Пеший маршрут проверяется до старта: нужный этаж, непрерывная поверхность,
  настоящий конец найденного пути и препятствия. Неполный путь больше не
  принимается только потому, что движок добавил к нему точку цели.
- Отмена прекращает также поиск, следование и движение к границе зоны.
  Запоздавший результат расчёта не возобновляет отменённое назначение.
- Потеря цели, смена зоны или неподтверждённая замена пути прекращают старое
  движение. Переместившаяся цель вызывает ограниченный новый расчёт;
  постоянное движение обслуживает режим следования.
- Следование останавливает старый путь, когда цель вернулась близко к игроку,
  и прекращает бесполезные повторы при застревании. Долгий расчёт не лишает
  персонажа времени начать движение.
- Подход к записанному переходу тоже проверяется. Пустой список точек вдали
  от выхода не означает прибытие. Для границы зоны сохраняется её настоящая
  точка входа, а последний короткий подход ограничен по времени и продвижению.
- Клавиша остановки активной навигации работает в режиме чтения таблицы
  и редакторе количества. Полёт получает отменяемый запрос и проверку конца;
  неудачная посадка сообщает об отказе.
- Включены изменения 6.08.87: подход к Ивейну и Джиллиан, чтение описания класса
  по строке под курсором и озвучка очереди на вход без перебивания списком персонажей.

## Скачать и обновить

- **FF14AccessibilityInstaller.exe** — автоматический установщик 1.1.2.
  Закройте FFXIV и XIVLauncher, запустите EXE и выберите обновление мода.
  Установщик скачивает последний стабильный выпуск и сохраняет резервную копию.
- **FF14Accessibility-6.08.88-RU-no-source.zip** — готовый мод для ручной установки:
  папка `plugin`, инструкция и лицензии, без исходников, EXE и скриптов установки.
- **SHA256SUMS.txt** — контрольные суммы ZIP, DLL, установщика и его исходников.
- **FF14AccessibilityInstaller-1.1.2-source.zip** и GitHub Source code — исходники
  для разработчиков.

Нужны Windows x64, FFXIV с Dalamud API 15, vnavmesh для маршрутов и скринридер.
[Инструкция по установке](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/installation.md).

## Что подтверждено

По сохранённым картам установленного vnavmesh проходят 69 маршрутов в 12 вариантах
карт и оба прежних проблемных подхода в Старой Гридании. Проверки покрывают
неполные пути, смену зоны и цели, отмену расчёта, замену маршрута, препятствия,
обходы, остановку в режимах чтения и длительное следование.
Release собран без предупреждений и ошибок. Пройдены **542 теста** без пропусков
и десять проверок запрета упаковки без актуальных результатов. В ZIP готового
мода **141 файл**; состав и контрольная сумма каждого файла сверены со сборкой.
Точные результаты общей сборки, тестов и проверки ZIP — в
[VERIFICATION.md](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/maintenance/VERIFICATION.md).

[Подробный разбор](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/maintenance/NAVIGATION_REVIEW.md)
содержит причины, исправления, использованные исходники и ограничения.
Новая сборка не устанавливалась в работающую игру и не проверялась в FFXIV/NVDA/Tolk.
Проверки сохранённых карт не вызывают текущие столкновения игры и не охватывают
все зоны; они не доказывают безошибочное прохождение всех мест.
