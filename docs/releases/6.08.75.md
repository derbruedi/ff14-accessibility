# FF14 Accessibility 6.08.75 — локальная сборка

- Исправлен Alt+F3 при русском пункте меню «Положить в арсенал».
- Ctrl+Num0 открывает выбор клавиши даже при включённом режиме геймпада.
- Подключено меню игрока из истории чата по Ctrl+Shift+Page Up. Одноимённые
  игроки с разных серверов больше не смешиваются.
- Исправлены проценты здоровья при больших значениях, в том числе у боссов.
- Повторное отключение модов Penumbra сохраняет список для восстановления.
  После частичной ошибки повтор восстановления обрабатывает оставшиеся записи.
- Журнал предыдущего запуска сохраняется в папке logs рядом с модом.
- Устранены предупреждения сборки, расширены автоматические проверки.

Архив готового плагина не содержит исходников, отладочных файлов и установочных
скриптов. Выпуск не опубликован. Автоматические тесты и установка не заменяют
повторную проверку клавиш и переноса предметов в запущенной FFXIV.
