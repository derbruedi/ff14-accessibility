# FF14 Accessibility 6.08.121 — подземелья и новые возможности автора

Добавлено совместимое исправление для обновлённой крепости Дземаэль:
проверенная vnavmesh 1.2.3.14 теперь использует авторскую настройку дверей
и в новой территории 1330. При первом включении навигации в этой зоне
потребуется дождаться перестроения сетки и повторно включить движение.
Файлы и настройки vnavmesh сохраняются. Если зависимость уже умеет работать
с новой крепостью, её поддержка остаётся без подмены.

Записанные точки подземелья сохраняют этаж; механизмы определяются по номеру
объекта из маршрута, положению и высоте. Добавлены команды:

- `/acc navstatus` — состояние сетки и доступных точек подземелья;
- `/acc navrebuild` — перестроение сетки с остановкой текущего движения.

Из неопубликованной ветки оригинального мода перенесены инвентарь по категориям
с игровым меню предмета, группы классов в оружейном сундуке, чтение пустых слотов,
прочности и связи с духом, чтение обмена между игроками, места охотничьего журнала,
действующие сезонные события, подсказки для трасс Столпервиля и штатное удержание
кнопки подтверждения. Сообщения и подписи доступны по-русски.
Ctrl+F3 открывает категории инвентаря; Num0 открывает категорию и меню предмета.
В оружейном сундуке Num0 входит в выбранную группу классов, плюс возвращает к ним.

Сохранены полные параметры предметов, русские справочники, функции V19,
точные объекты и наши более поздние исправления заданий, обучения и чтения кнопок.
Дружественные боевые NPC дополнительно распознаются по признаку самой игры;
неизвестные состояния не скрывают потенциальных противников.

Сборки прошли без ошибок и предупреждений; все 1 316 тестов в семи проектах,
проверки навигации и упаковки прошли. Проверены файлы 235 территорий,
настоящие игровые таблицы и регистрация совместимости в установленной DLL
vnavmesh. В игровом архиве 141 файл, все сверены по SHA-256.
Движение в крепости и новая речь в FFXIV/NVDA/Tolk ещё требуют проверки в игре.
Сбой из сообщения пользователя без журнала этой попытки не считается полностью
воспроизведённым. Подробности: DUNGEONS_UPSTREAM_608121.md в документации проекта.

Для установки используйте FF14AccessibilityInstaller.exe или ручной архив
FF14Accessibility-6.08.121-RU-no-source.zip. Игровой ZIP не содержит исходников.
Отдельный архив исходников установщика предназначен для разработчиков.
