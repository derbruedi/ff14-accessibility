# FF14 Accessibility 6.08.107 — навигация к входам в другие зоны

Исправлен отказ «Защитить Хранителя в другой зоне, и я не нахожу туда перехода».
Из Новой Гридании Num3 ведёт к охраннику входа в Обитель Первого Лука.
Рядом выбирается нужный охранник; нажмите Num0 и подтвердите вход в игре.
После перехода выберите цель задания и снова нажмите Num3. Из Старой Гридании
первый участок ведёт в Новую Гриданию, откуда доступен вход к охраннику.

Поиск пути учитывает проверенные входы через игровые объекты и двери,
которые отсутствуют среди обычных переходов карты. Используются реальные
номера и положение входа в исходной зоне. Условия доступности и подтверждение
входа определяет игра. Неизвестные входы через NPC не угадываются.

Сохранены чтение Project Prima через Harmonia, исправления штатных кнопок,
русская речь и прежние изменения 6.08.106. При наличии переведённого текста
в игре он читается раньше собственных справочников; `/acc translate off`
выключает собственный перевод плагина. Установщик 1.3.0 и его исходники сохранены.

Это обновление существующей записи выпуска 6.08.106 до 6.08.107.
Исходная метка v6.08.106 сохраняется; исходники новой сборки доступны
по метке v6.08.107. ZIP плагина не содержит исходников.

Проверки данных игры: восемь входов на восьми картах, 29 утверждений,
маршруты из Новой/Старой Гридании и обратный выход. Дополнительно прошли
16 новых тестов связей и выбора точного объекта. Общая проверка: 1 012 тестов
без пропусков, сборка без ошибок и предупреждений, ZIP из 141 проверенного
файла без исходников. Окончательные результаты
общей проверки приведены в [отчёте](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/maintenance/VERIFICATION.md).
Запуск новой сборки в FFXIV, фактический вход, движение и NVDA/Tolk пока не проверены.

Файлы выпуска:

- `FF14AccessibilityInstaller.exe` — установка и обновление, установщик 1.3.0.
- `FF14Accessibility-6.08.107-RU-no-source.zip` — ручная установка плагина.
- `SHA256SUMS.txt` — контрольные суммы архива, DLL и установщика.
- `FF14AccessibilityInstaller-1.3.0-source.zip` — исходники прежнего установщика.
- Архивы GitHub Source code — исходники плагина по новой метке v6.08.107.

Обновляйте при закрытых FFXIV и XIVLauncher, затем полностью перезапустите игру.
