# FF14 Accessibility 6.08.83 — описания классов при создании персонажа

Исправлен случай, когда при выборе класса читалось описание города, а описание
самого класса отсутствовало. Выпуск включает все изменения предыдущей 6.08.82.

## Скачать и обновить

- **[Автоустановщик для Windows](https://github.com/pitpamyati-netizen/ff14-accessibility/releases/download/v6.08.83/FF14AccessibilityInstaller.exe)** — закройте FFXIV и XIVLauncher, запустите и выберите установку или обновление.
- **[ZIP для ручной установки](https://github.com/pitpamyati-netizen/ff14-accessibility/releases/download/v6.08.83/FF14Accessibility-6.08.83-RU-no-source.zip)** — готовый плагин без исходников; инструкция находится внутри.
- `SHA256SUMS.txt` — контрольные суммы. Исходники установщика 1.1.2 доступны отдельным архивом, исходники плагина — через GitHub Source code.

## Причина и исправление

В журнале версии 6.08.82 от 30 сентября, 23:13, игра показывала персонажа
с обычным стартовым оружием. Прежняя проверка знала только другой, показной
набор оружия и поэтому не определяла класс. Одновременно общий читатель
реагировал на изменение соседнего окна города и перебивал название класса.

- Теперь учитываются оба набора оружия из таблиц игры. Все части модели
  сравниваются точно, кроме красителей; неизвестный класс не угадывается.
- Название и описание берутся для одного распознанного класса. Быстрая смена
  класса отменяет прежнее отложенное описание; Ctrl+F10 повторяет текущее.
- Пока открыт выбор класса, город не читается автоматически. За пределами
  этого шага его обычное чтение сохранено.
- Русские названия классов сохранены. Описания используют язык игровых таблиц,
  включая загруженный перевод XIV Rus; отдельный перевод здесь не добавлялся.

## Проверка и ограничения

Сборка завершена без ошибок и предупреждений. Пройдены **394 теста** без
пропусков и **десять проверок запрета выпуска**. Дополнительно выполнены
**128 проверок классов и описаний по установленным игровым таблицам**:
реальное оружие из журнала и показное, четыре языка клиента и два языка плагина.
Все **141 файл ZIP** сверены по SHA-256; исходников в архиве плагина нет.
Подробные результаты записаны в `docs/maintenance/VERIFICATION.md`.

**Новая версия ещё не проверена в запущенной FFXIV.** После обновления нужно
перебрать восемь стартовых классов, задерживаясь на каждом для описания,
проверить быстрое переключение и Ctrl+F10. Должно звучать описание выбранного
класса; описание города не должно перебивать его.
