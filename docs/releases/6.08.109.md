# FF14 Accessibility 6.08.109 — последовательные маршруты заданий

Исправлены повторные отказы для «Посол из Гридании» и «Два клинка в руках».
Путь из Новой Гридании учитывает воздушное сообщение в Лимсу, подъёмник
посадочной площадки и отдельный вход к разбойникам. Разные этажи одной
территории больше не считаются местом, к которому можно сразу идти напрямую.

Общий механизм строит последовательность через подтверждённые NPC, двери
и пешие границы. Текущая цель перечитывается перед действием и после изменения
этапа; выбор задания сохраняется при переходе. Нужный объект определяется
по номеру, типу, месту и этажу, без подмены другим NPC или старой боевой целью.
Если требуется телепортация, называется уже открытый эфирит с продолжением
пути; для подземелий используются реальные внешние входы и доступный поиск.

Управление: Num3 ведёт по следующему участку. У NPC/двери нажмите Num0,
выберите названное место и подтвердите в игре. После перехода снова нажмите
Num3. Подтверждения, плата и сюжетная доступность остаются действиями игры.

На установленной игре просмотрены все 1 231 карты и 26 726 расположений
квестовых NPC/объектов. Проверены 315 входов на 147 исходных картах,
2 305 утверждений и четыре задания из журналов. Полная проверка прошла:
1 065 тестов без пропусков, сборка без ошибок и предупреждений,
ZIP — 141 проверенный файл без исходников. Результаты приведены в
[отчёте проверок](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/maintenance/VERIFICATION.md).

Ограничение: для 106 строк карты назначения из общей проверки подтверждённый
вход не найден, в том числе для ряда сценарных помещений. Это не число
сломанных квестов. Сопровождение всех квестов без исключения пока не доказано.
Живое движение, переходы и NVDA/Tolk ещё не проверены. Подробности охвата и
порядок проверки — в
[описании навигации](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/quest-navigation.md).
