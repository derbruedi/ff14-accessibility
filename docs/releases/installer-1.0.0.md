# Автоустановщик FF14 Accessibility 1.0.0

[Скачать EXE](https://github.com/pitpamyati-netizen/ff14-accessibility/releases/latest/download/FF14AccessibilityInstaller.exe) · [Полная инструкция](../installation.md).

Один файл для Windows x64 со встроенным .NET. При открытии проверяет версию;
по кнопке «Установить / обновить мод» скачивает последний стабильный выпуск
русской версии, проверяет файлы, копирует их и включает мод в Dalamud.
Перед заменой сохраняет резервную копию. При ошибке записи восстанавливает
прежние файлы и настройки. Более старая версия не заменяет новую.

Нужны установленный XIVLauncher, созданные настройки Dalamud и закрытые игра
и лаунчер перед установкой. В конце можно согласиться на добавление vnavmesh,
если она отсутствует. Установленную vnavmesh EXE автоматически не обновляет.

Для переходов между журналом и кнопками предусмотрены Tab и Shift+Tab.
Журнал и кнопки доступны через средства доступности Windows; чтение NVDA
и реальные переходы с клавиатуры ещё требуют проверки.

Пройдены 34 автоматических сценария установщика, включая возврат файлов
после ошибок. Проверены настоящие скачивания и установка в отдельную папку.
Это не проверка загрузки плагинов и их речи в FFXIV.

Исходники, тесты и инструкция сборки находятся в отдельном
`FF14AccessibilityInstaller-1.0.0-source.zip` на странице релиза.
Контрольные суммы EXE и этого ZIP — в `installer-SHA256SUMS.txt`.
ZIP готового мода предназначен для ручной установки и не содержит установочных скриптов.
