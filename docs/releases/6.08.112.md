# FF14 Accessibility 6.08.112 — поисковые круги и переходы на всех известных маршрутах

Исправлен повторный отказ «Нет проходимой точки у Дилемма изящного вкуса».
Новый журнал показал, что игра всё ещё загружала 6.08.110; локальная 6.08.111
не была опубликована. Этот выпуск включает её исправление: поисковая область
получает высоту проходимой поверхности, а высота центра круга не считается
этажом NPC. Если центр недоступен, проверяются другие точки внутри круга
с запасом для остановки. Правило общее, без исключения по номеру задания.

Дополнительно исправлены отказы выбора первого перехода на повторной строке
той же физической карты. Поиск находил путь из Zero's Domain, но выбирал
значок по другой строке карты и не мог начать движение. Теперь поиск пути
и выбор первого шага используют одну строку; разные этажи не объединяются.

На данных установленной игры проверены все 1 231 исходные строки карты
и 31 833 пары с известными связями. Обнаруженные шесть отказов выбора
первого шага устранены; после исправления таких отказов нет. Проверка
выполнила 141 405 утверждений, сохранив проверки 315 входов, 125 пеших
объёмов и 5 689 поисковых отметок. Ответ сетки для записанного сбоя
воспроизведён по журналу. Остальные радиусы и поверхности кругов имитируются.

Проверка всех таблиц и известных маршрутов не означает прохождение всех
карт в FFXIV. Для 106 строк карты квестовой цели подтверждённый маршрут
из Новой Гридании с учётом дополнительных средств отсутствует. Неизвестные
сценарные входы, закрытый по сюжету транспорт, живое движение, выполнение
заданий и NVDA/Tolk не проверены. Гарантии «всегда на любой карте» нет.
Переходы и разговоры подтверждает игрок в обычном окне игры.

Полная проверка прошла: сборка Release без ошибок и предупреждений,
1 116 тестов без пропусков, 11 проверок защиты упаковки. Прежние защищённые
12 файлов и два метода навигации автора сохранены. ZIP содержит 141 файл;
состав и контрольные суммы сверены.

Для обновления используйте `FF14AccessibilityInstaller.exe`.
В игровом архиве `FF14Accessibility-6.08.112-RU-no-source.zip` исходников нет.
Исходники установщика находятся в отдельном архиве; исходники плагина —
в репозитории GitHub. После обновления версия при запуске должна быть 6.08.112.
