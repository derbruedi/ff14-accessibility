# FF14 Accessibility 6.08.89 — выход из гильдии копейщиков

Исправлена подготовка пешего пути после отказов версии 6.08.88 при выходе
из гильдии копейщиков. Проверка живых препятствий выполняется рядом с игроком
и перед каждым следующим шагом. Дальние изменяемые препятствия не запрещают
весь маршрут до начала движения. Непрерывный пол, нужный этаж и настоящий
конец пути по-прежнему проверяются по всей длине.

Обычные места на карте сначала ищут пол возле своей горизонтальной метки.
Это устраняет выбор неверного высокого участка вместо Западного причала
при запуске из гильдии. Если рядом с меткой нет пола, сохранён прежний поиск
более широкого подхода. Цели NPC, рыбалка и настоящие границы зон сохраняют
свои правила.

При столкновении журнал теперь записывает точное место и свойства препятствия.
Старый журнал не позволял назвать конкретный объект, поэтому причина
конкретного попадания и реальное прохождение требуют проверки в игре.

Автоматически пройдены 549 тестов без пропусков, 69 маршрутов сохранённых
карт и шесть проверок гильдии/причала. ZIP содержит 141 файл готового мода,
инструкцию и лицензии без исходников; все контрольные суммы проверены.

6.08.89 установлена локально при закрытой игре с полной резервной копией.
Автоматическая проверка и установка не подтверждают реальный выход
в работающей FFXIV/NVDA/Tolk. Выпуск ещё не опубликован; серверный установщик
получает опубликованную 6.08.88, а не эту локальную сборку.
