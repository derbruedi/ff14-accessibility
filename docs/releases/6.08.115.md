# FF14 Accessibility 6.08.115 — чтение арсенала

При выборе вещи в арсенале теперь звучат уровень предмета, защита или урон,
задержка оружия, прибавки к характеристикам и число гнёзд материи, если эти
значения есть в игровых данных. Раньше общий список использовал сокращённое
чтение, предназначенное для обзора надетого снаряжения, и опускал параметры.

Num5 и Ctrl+F10 повторяют параметры вместе с дополнительным описанием,
прочностью и предупреждением о комплекте. Обновление невидимых данных вещи
не перебивает речь. Перед Num0 по-прежнему проверяется конкретный экземпляр.
Ручное чтение записывает полное описание в журнал для дальнейшей диагностики.

Числа берутся из базовой строки предмета. Для высокого качества и вставленной
материи это прямо объявляется: их бонусы в эти числа не входят. Окончательные
значения конкретного экземпляра доступны через штатное «Сравнить предмет».

Также исправлены ступени магазина великой компании: категории самого магазина
больше не сравниваются с неиспользуемыми будущими рангами. Одинаковые
предупреждения не повторяются каждый кадр; при неизвестной структуре остаётся
безопасное чтение позиции.

Проверки прошли: сборка без ошибок и предупреждений, 1 172 теста без
пропусков, 11 проверок защиты упаковки. Проверка игровых таблиц включает
801 утверждение и параметры 12 вещей из журнала. Игровой ZIP содержит
141 файл; состав и контрольные суммы всех записей проверены.

Исходный журнал относится к версии 6.08.104. Новая версия сохраняет исправления
6.08.105–6.08.114. Полный разбор и результаты:
[VERIFICATION.md](../maintenance/VERIFICATION.md).
Живое чтение и действия в FFXIV/NVDA/Tolk новой версии ещё не проверены.

Для установки используйте FF14AccessibilityInstaller.exe либо
FF14Accessibility-6.08.115-RU-no-source.zip. Игровой архив без исходников;
исходники установщика опубликованы отдельным ZIP.
