# FF14 Accessibility 6.08.120 — объекты навигатора и чтение кнопок

Исправлено общее правило, из-за которого именованные двери, механизмы
и другие объекты окружения исчезали из навигатора, когда их временно
нельзя было выбрать целью. Теперь они остаются в списке с указанием
недоступности. Взаимодействие по Num0 по-прежнему требует разрешения игры
и обращается к выбранному экземпляру. Пустые точки сбора, открытые сундуки
и безымянные недоступные объекты остаются скрытыми.

Исправление чтения кнопок распространено на общий читатель окон.
Безымянная кнопка больше не получает текст соседних кнопок из общего
контейнера. Фокус сопоставляется с его собственным управлением, в том числе
при неполной связи внутренних элементов окна. Скрытые подписи исключены,
однобуквенные обозначения читаются, служебная разметка игры удаляется.
Добавлены проверки принадлежности окна и доступности в обучении и арене.
Штатные действия игры, отметка ознакомления и подтверждение с удержанием
сохранены.

Журнал навигатора теперь содержит сведения о конкретных включённых
и исключённых объектах, чтобы следующую жалобу можно было расследовать
по имени и номеру объекта.

Основание — текущий код и доступный локальный журнал. Журналов других
игроков нет; охват всех их случаев не подтверждён. Автоматические проверки
и границы результата: [VERIFICATION.md](../maintenance/VERIFICATION.md).
Release собран без ошибок и предупреждений; все 1 222 теста в семи
проектах прошли без пропусков, защита навигации и упаковки прошла.
В игровом архиве 141 файл, все сверены по SHA-256.
Включены исправления чтения обучения «Подземелья» из локальной 6.08.119.
Новая версия требует проверки в FFXIV с NVDA/Tolk; успешная сборка
и тесты не являются подтверждением работы всех окон и объектов в игре.

Для установки используйте FF14AccessibilityInstaller.exe или ручной
архив FF14Accessibility-6.08.120-RU-no-source.zip. Игровой архив не содержит
исходников. Отдельный архив с исходниками установщика нужен разработчикам.
