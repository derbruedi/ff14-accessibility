Установка FF14 Accessibility

Версия мода в этом архиве: 6.08.122.
Пакет версии 6.08.122 русской версии FF14 Accessibility.
Для установки именно этой версии используйте папку plugin из этого архива.
Автоустановщик скачивает последний стабильный выпуск нашего репозитория.

Файлы опубликованных выпусков: https://github.com/pitpamyati-netizen/ff14-accessibility/releases/latest

Навигация в обновлённой крепости Дземаэль

При первом включении движения со старой vnavmesh 1.2.3.14 мод применит
исправление автора для новой зоны и попросит дождаться перестроения сетки.
После ожидания снова включите движение. /acc navstatus читает состояние сетки,
/acc navrebuild запускает её перестроение вручную и останавливает текущее движение.
Файлы и настройки vnavmesh сохраняются. Прохождение крепости ещё требует проверки
в игре; исправление не обещает работу любого пути в любом подземелье.

Ctrl+F3 открывает категории инвентаря, Num0 входит в категорию и открывает игровое
меню предмета. В оружейном сундуке сначала выбирается группа классов; Num0 входит,
плюс возвращает к группам. Добавлено чтение обмена между игроками, мест охотничьего
журнала, текущих сезонных событий и подсказок трасс Столпервиля.

Какой файл выбрать

- FF14AccessibilityInstaller.exe — автоматическая установка и обновление.
  Он сам скачивает мод, копирует файлы и включает его в Dalamud.
- FF14Accessibility-6.08.122-RU-no-source.zip — ручная установка.
  Содержит папку plugin, инструкцию и лицензии, без скриптов, EXE и исходников.
- Source code и FF14AccessibilityInstaller-1.3.0-source.zip — исходный
  код для разработки. Для установки готового мода эти архивы не нужны.

Подготовка

Нужны Windows x64, FFXIV, XIVLauncher: https://goatcorp.github.io/ с включённым
Dalamud и настроенный скринридер, например NVDA. Версия плагина 6.08.122
собрана с Dalamud 15.0.3.7 / API 15 для игры 2026.10.06.0000.0000.
Обновите Dalamud штатным способом через XIVLauncher. Загрузка, речь
и управление в обновлённой игре ещё требуют отдельной проверки.

При первой настройке XIVLauncher сначала войдите в игру с включённым Dalamud,
чтобы создались его настройки. Затем закройте FFXIV и XIVLauncher.

Автоматическая установка через EXE

1. Скачайте FF14AccessibilityInstaller.exe: https://github.com/pitpamyati-netizen/ff14-accessibility/releases/latest/download/FF14AccessibilityInstaller.exe и запустите его.
   Интернет нужен для проверки версии и скачивания файлов. .NET уже включён в EXE.
2. Дождитесь результата проверки в журнале. Само открытие окна ничего не устанавливает.
3. Нажмите «Установить / обновить мод» и дождитесь сообщения о результате.
4. Если vnavmesh отсутствует, установщик предложит добавить её. Она нужна для
   движения по рассчитанным маршрутам; её установка необязательна для озвучивания.
5. Запустите игру через XIVLauncher и введите /acc lang ru для русского языка плагина.

Установщик скачивает последний стабильный выпуск из этого репозитория,
проверяет контрольную сумму и включает плагин в Dalamud. Чтобы проверить
и установить следующее обновление, снова запустите этот EXE.
Установленная более новая версия сохраняется. Существующую vnavmesh
установщик обнаруживает, но автоматически её не обновляет.

Для перехода между журналом и кнопками предусмотрены Tab и Shift+Tab,
для нажатия выбранной кнопки — Enter или пробел. Журнал можно читать стрелками,
Ctrl+Home и Ctrl+End; выделенный текст копируется через Ctrl+C.
Доступность элементов окна проверена; чтение NVDA и реальные переходы по Tab
ещё требуют проверки со скринридером.

Перед заменой сохраняются прежние файлы и настройки Dalamud. Обычное место копий:
%APPDATA%\XIVLauncher\installer-backups. Точный путь указан в журнале.
При ошибке записи установщик возвращает прежние файлы и настройки.
Если обнаружены несколько копий плагина или неизвестная настройка Dalamud,
следуйте сообщению журнала: установщик остановится и объяснит причину.

Ручная установка из ZIP

1. Распакуйте полученный архив 6.08.113 в отдельную папку. Эта инструкция относится к содержимому архива; ссылка releases/latest ведёт на последний опубликованный выпуск и может предлагать другую версию.
2. Закройте игру и XIVLauncher. Если обновляете установленный мод, сохраните
   копию всей его прежней папки в другом месте.
3. Нажмите Win+R, введите %APPDATA%\XIVLauncher\devPlugins и нажмите Enter.
   Если папки devPlugins нет, создайте её в %APPDATA%\XIVLauncher.
4. Создайте внутри папку FF14Accessibility и скопируйте в неё всё содержимое
   папки plugin из архива, включая подпапки. DLL должна оказаться по адресу
   %APPDATA%\XIVLauncher\devPlugins\FF14Accessibility\FF14Accessibility.dll,
   без дополнительной папки plugin между ними.
   Если плагин уже зарегистрирован в другом месте, обновите именно ту папку.
5. Запустите игру через XIVLauncher. При первой установке откройте настройки
   Dalamud командой /xlsettings, раздел Experimental, список
   Dev Plugin Locations. Добавьте полный путь к FF14Accessibility.dll
   и сохраните настройки. В поле нужен полный путь, который Проводник показывает
   вместо %APPDATA%, например C:\Users\Имя\AppData\Roaming\XIVLauncher\devPlugins\FF14Accessibility\FF14Accessibility.dll.
6. В списке плагинов Dalamud (/xlplugins) найдите FF14Accessibility,
   включите его и загрузку при запуске. При обновлении уже зарегистрированной
   копии повторно добавлять тот же путь не нужно.
7. Введите /acc lang ru. Для маршрутов отдельно установите совместимую vnavmesh.

Ручной способ требует настройки в окнах Dalamud, доступность которых для
скринридера ограничена. EXE выполняет эту настройку автоматически.
Добавление DLL описано также в документации Dalamud: https://dalamud.dev/faq/getting-started/.

Настройки плагина в pluginConfigs при обычном обновлении сохраняйте.
Для русской версии используйте выпуски этого репозитория; установщик исходного
проекта скачивает другую сборку. Не включайте две копии FF14Accessibility одновременно.

После установки

Арсенал: Ctrl+I открывает общий список. Num4/6 выбирают соседние вещи,
Num2/8 переходят по строкам, Num7/9 — по непустым категориям.
При выборе читаются параметры вещи. Num5 или Ctrl+F10 повторяют их
вместе с дополнительным описанием, прочностью и предупреждением о комплекте.
Для высокого качества и вставленной материи числа объявляются базовыми,
без их бонусов. Окончательные значения экземпляра проверяйте через штатное
«Сравнить предмет». Num0 открывает меню именно выбранной вещи.
Живое чтение новой версии в FFXIV/NVDA/Tolk ещё требует проверки.

Покупка нескольких штук одного товара за гил:
1. Выберите товар в обычном магазине. Нажмите Ctrl+Shift+B.
2. Прослушайте название и допустимое количество. Введите число, например 50,
   цифрами верхнего ряда или цифровым блоком с включённым Num Lock.
   Первая цифра заменяет прежнее число. Backspace удаляет цифру, Delete очищает.
3. Enter задаёт количество. Затем подтвердите покупку обычной клавишей игры,
   как правило Num0, и ответьте на подтверждение, если оно появится.
4. Escape отменяет только ввод. Смена товара или закрытие магазина также
   отменяет его. Если поле количества скрыто, сначала откройте его в игре.
Справка магазина: Ctrl+F1. Обмен за другие валюты и продажа не поддержаны.
Эта функция проверена автоматически; проверка новой версии в FFXIV ещё нужна.

/acc lang ru выбирает русский язык озвучивания, /acc help открывает справку,
/acc keys сохраняет список клавиш на рабочем столе. Сохранённые пользователем
сочетания клавиш могут отличаться от стандартных.

Если плагин не загрузился, проверьте совместимость Dalamud, путь к DLL и наличие
всех файлов из plugin. При обращении за помощью приложите текст ошибки,
версию плагина и последовательность действий. Сообщить о проблеме: https://github.com/pitpamyati-netizen/ff14-accessibility/issues/new/choose.


В 6.08.93 специальные эффекты классов, в том числе «Ястребиный глаз» барда,
озвучиваются через канал готовности умений. Команда /acc cooldowns переключает
оба вида сообщений. Одновременные готовности объединяются в одну фразу.
При недоступности отдельного голоса используется экранный диктор.

Автонавигация с 6.08.91 возвращена к реализации автора. При чтении цели
по Num5 звучит её направление, расстояние и высота без запуска движения.
Обновления автора до 6.08.35 и русская речь лотерей/книги зверей включены.
Речь и движение новой версии в FFXIV ещё нужно проверить.

Новое в 6.08.78: окно C, таблицы и навыки на P

В 6.08.81 исправлено смешивание характеристик при чтении. В окне C сначала
читаются показатели, затем кнопки окна. Каждая характеристика читается отдельно
со своим числом; атака, защита, магия и другие группы разделены. ОЗ и ОМ читаются
с текущим и максимальным значением. Заголовок звучит при переходе в раздел,
а не перед каждой строкой. Tab/Shift+Tab переходят между этими группами.

Откройте окно персонажа или другую таблицу и нажмите Ctrl+Alt+F10.
Вверх/вниз или Num8/2: строки. Влево/вправо или Num4/6: поля строки.
Page Up/Down: десять строк. Home/End: начало/конец. Tab/Shift+Tab: раздел.
Num5 или пробел: повтор с обновлёнными данными. Escape: выход из чтения.
Ctrl+F1: справка. Ctrl+F11: остановка речи.
Это только чтение: Enter и Num0 не нажимают кнопки игры. Для действий
и смены вкладки сначала выйдите из чтения. Значки без текста и незагруженные
строки могут отсутствовать. Режим закрывается при смене окна.

В окне P выберите умение и нажмите Ctrl+F10: название и описание.
Исправлено распознавание английских названий пассивных навыков с русским уровнем.
Добавлены русские описания общих действий, команд питомца и главного меню.
Для русского языка: /acc lang ru. Неизвестные записи используют текст игры.
/acc translate off отключает русский перевод названий и описаний предметов и умений в озвучке.
/acc translate on возвращает перевод; /acc translate сообщает состояние.
Можно также: /acc перевод выкл и /acc перевод вкл. Настройка сохраняется после перезапуска.
Русские подсказки плагина остаются. При отключении читаются данные игры;
При Project Prima / Harmonia читается перевод из самой игры: собственные переводы плагина не перекрывают его. Команда translate off сохраняет такой текст. Перевод видимых окон управляется отдельно в Harmonia или XIV Rus/Penumbra.
Версия автоматически проверена, но её речь в запущенной FFXIV агент не проверял.

Следование за целью — Alt+F

С версии 6.08.80 Alt+F включает и выключает следование за выбранной целью.
Прежнее назначение на = / + заменяется автоматически при загрузке плагина.
Теперь спринт на клавише = не должен включать следование. Нужна vnavmesh.
При вводе текста Alt+F остаётся доступно игре.

Системные настройки звука: ползунки читают конкретный канал и процент.
Точное значение: Ctrl+Enter на выбранном ползунке, число 0–100, Enter.
Escape отменяет ввод. Для сохранения нажмите «Применить» в игре.

Автоповорот при опасной зоне AoE

Включение: /acc aoeturn on; отключение: /acc aoeturn off.
Без аргумента /acc aoeturn читает состояние; переключатель есть в Shift+F9.
По умолчанию выключено. Для распознанного круга вокруг противника или конуса
плагин проверяет прямой выход и поворачивает персонажа и камеру.
После повторной проверки звучит Вперёд и расстояние; двигайтесь сами.
Если поворот не подтверждён, уклоняйтесь вручную. Ручное управление и
остановка (Ctrl+F11 или /acc stop) отменяют помощь. В меню, чате, при Alt+Tab и автоматическом беге
поворот блокируется. Живая проверка и замер нагрузки ещё требуются.
